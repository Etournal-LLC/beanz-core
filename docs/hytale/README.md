# Hytale engine notes

Reference for working on beanz-core against the Hytale server API (built and tested on 0.7.7).

- `shards-bs0-findings.md` — Shards BS0 spike: what was proven, the ability-key options, the in-game test list
- `catalogs/` — every built-in particle system, sound event and entity effect name (tab-separated: name, folder)
- `schema-0.7.7/` — JSON schemas for EntityEffect, Interaction, RootInteraction, Item, ItemDropList, exported with
  `HytaleServer.jar --generate-asset-schema <dir>`
- `abilities/`, `interactions/`, `ui/`, `commands/` — older notes from the Jump/Sky Leap work (some files are empty stubs)
